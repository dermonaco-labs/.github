# derMonaco Labs Organization Policy

Shared community-health files and governance guidance for repositories in the
`dermonaco-labs` GitHub organization.

This repository is intended to be public. It must contain only reviewed,
sanitized policy and reusable material. Application source, deployment
inventories, live environment identifiers, credentials, and private operational
details do not belong here.

GitHub uses these files as defaults for organization repositories that do not
define their own file of the same type. A repository-local file takes
precedence.
